## How it works

There are two pieces:

**1. Register the mark** via the `extensions` field of `text-options`:

```vue
<WovenCanvas :text-options="{ extensions: [Highlight.configure({ multicolor: true })] }" />
```

**2. Drive it by name.** `useTextFormatting` exposes a generic mark handle that works
in both edit mode (the active TipTap selection) and batch mode (across selected blocks):

```ts
const { commands, getMarkAttrs } = useTextFormatting(() => entityIds)

// Read the current highlight color (null if none or mixed). Reactive — use in a computed.
const color = computed(() => getMarkAttrs('highlight')?.color ?? null)

// Apply / clear
commands.setMark('highlight', { color: '#FEF08A' })
commands.unsetMark('highlight')
```
